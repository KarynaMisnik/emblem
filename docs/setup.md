# 🦫 Project Setup

### Create project

<code> npx create-expo-app coat-of-arms</code>

### Install dependencies

<code>npx expo install</code>

> **the command is used when:**<br>
> 🪵 cloning the repository<br>
> 🪵 dependencies change<br>
> 🪵 <code>node_modules</code> is missing<br>

### Start project

<code>npx expo start</code>

> the command is used when:<br>
> developing the project. You need it everytime to start the development server.

### Development workflow

1. Open project.
2. Run <code>npx expo start</code>.
3. Press `w` for web or scan the QR code with Expo Go.
4. Edit code in VS Code.
5. Save (`Ctrl + S`).
6. Expo automatically refreshes the app.
